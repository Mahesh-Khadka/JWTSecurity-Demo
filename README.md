# JWTSecurity-Demo

A simple Spring Boot project demonstrating **JWT-based authentication**.

## 🔐 Overview
This project implements a basic **login system** using **Spring Security** and **JSON Web Tokens (JWT)**.  
When a user logs in successfully, the backend generates a JWT token, which can be used to access protected routes.

## 🧰 Tech Stack
- Java 17
- Spring Boot
- Spring Security
- JWT Authentication
- JPA / H2 Database

## 🚀 How to Run
1. Clone the repository:
   git clone https://github.com/Mahesh-Khadka/JWTSecurity-Demo.git
2. Run the application:
   mvn spring-boot:run
3. Use the /login endpoint to authenticate and receive a JWT token

🧠 Purpose:
This project is for learning and demonstrating how JWT authentication works in Spring Boot.
